# LoreLab 前端体验巡检

## 本轮方向

从喜欢日式动漫、原创角色和架空世界的创作者视角看，网站的优势是素材有画面感、内容能互相关联。继续优化的重点是让“我的角色”和“我的作品”更有存在感，同时让长时间输入更轻松。

本轮实现可切换套装：保留原有的「灵感手札」，新增偏日式中二动漫的「绯月档案」。使用电光紫、绯红、月蚀纹章、切角面板和章节编号；配合少量世界线文案。两套都支持浅色与深色，星图装饰可关闭。

入口位于顶部调色盘、桌面侧栏、手机「更多」与快捷命令。选择保存在本浏览器，刷新及切换页面后保留；不改变创作内容、AI 提示词、云同步和分享。旧用户默认保持经典套装，未知或损坏的套装配置回退到经典外观。

## 建议的后续优先级

| 优先级 | 页面 / 当前体验 | 建议 | 创作者得到什么 |
| --- | --- | --- | --- |
| P1 | 角色页已经有头像与立绘，但首屏仍以字段表单为主 | 将「编辑」与「档案预览」分开：预览用立绘、名字、别名、所属世界和一句核心设定组成档案封面；长字段折叠为章节 | 创作结果更像属于自己的角色档案，也更方便展示 |
| P1 | 文章工作台集中了列表、编辑与 AI 操作 | 加一个可退出的专注写作布局，收起侧栏和次要按钮，保留保存状态、章节切换与字数 | 写正文时更安静，工具仍随手可用 |
| P1 | 个人主页偏账号、同步和 AI 配置 | 为公开创作者主页增加可排序的代表作区；优先复用已有角色立绘，提供作品封面与一句推荐语 | 别人更快理解作者在写什么，也有自己的展示空间 |
| P2 | 关系网主要靠拖动、悬停和双击 | 加可点选的关系详情与邻接角色列表，键盘可选节点，手机点击后显示「查看档案」 | 更容易梳理羁绊、阵营和人物关系，也适合触屏 |
| P2 | 总览统计与最近编辑的信息较密 | 为活跃作品提供「继续这一章」的明确入口，把空白或未命名条目与成熟作品区分展示 | 每次回来都知道接下来写什么 |
| P2 | 大厅已有筛选分页，但作品分类偏工具术语 | 增加简短的题材与阅读信息层级；保留真实作品标题，不给全部内容强加中二命名 | 能更快找到同题材创作者 |
| P2 | 新创作者要自己理解角色、世界、组织、剧情的关系 | 设计「一句设定 → 一个角色 → 一段场景」的轻量起步流程，允许随时跳过 | 更快写出第一份自己的内容 |
| P3 | 手机底栏常用入口固定 | 根据实际使用反馈调整灵感、角色、写作的入口优先级，再决定是否支持自定义 | 高频创作少绕路 |

以上是后续建议，本轮实现范围为外观套装及其切换、兼容和验证。

## 设计边界

- 氛围文案用于首页、章节题记和社区横幅。保存、删除、公开 / 私有、同步、额度及错误提示保持明确。
- 使用现有原创插画，装饰由 CSS 与内联 SVG 绘制；不增加图库、生成图片或数据库请求。
- 正文字体、表单阅读顺序与输入内容不随套装变化。页面大标题采用有力度的黑体，避免装饰影响正文辨认。
- 不加入自动音效、闪屏、持续旋转或强制动效；继续尊重系统减少动画设置。
