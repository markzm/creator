# T03 —— Core 纯逻辑层 + 金标准单元测试

## 1. 背景与目标
构建 `web/src/core/` 纯 TypeScript 业务逻辑层（100% 无 DOM、无 Vue、无浏览器存储依赖），涵盖：
1. 与原版字节级兼容的草稿码编解码（`draftCode.ts`）、备份归一化与导出（`backup.ts`）、年份与时间线收集（`timeline.ts`）、一致性检查（`consistency.ts`）、文本/Markdown 格式化（`format.ts`）、关系网力导布局计算（`graphLayout.ts`）、字数与连续创作统计（`stats.ts`）、全局搜索与替换（`search.ts`, `glossary.ts`）。
2. **v6 新增核心能力**：
   - `schema/migrations.ts`：从 `cc_db_v5` / 任意旧备份平滑迁移到 `DocV6`（补齐所有实体的 `id / createdAt / updatedAt`，将根级 `activeW/activeO/activeC/activeTpl/nowYear` 收敛至 `ui` 字段）。
   - `diff.ts`：忽略 `ui` 字段的文档指纹计算（`computeSyncHash`）、差异摘要生成（`summarizeDocDiff`）以及**实体级/字段级自动三方合并（`threeWayMerge`）**。
   - `backlinks.ts`：Wiki 双向链接分词器（将纯文本安全切分为 `TextToken | EntityRefToken` 数组，杜绝 `v-html` XSS）与反向引用索引构建器（计算任意实体被哪些其他实体/事件/章节/场景提及）。

## 4. 详细实现要求
1. **金标准 100% 校验**：
   - `draftCode.spec.ts` 必须加载 `golden-draft-codes.json` 全部 200 组样本，验证 `buildCode` 输出与原版完全相等，`parseCode` 解出对象与原版完全相等。
   - `backup.spec.ts` 必须加载 `golden-backups.json`，验证所有历史格式（v4/v5/v5.1/v5.3/v6）均可无损归一化并升级为 `DocV6`。
   - `timeline.spec.ts` 必须加载 `golden-years.json`，验证所有年份字符串解析结果与原版一致。
2. **三方合并 (`threeWayMerge(base: DocV6 | null, local: DocV6, remote: DocV6)`)**：
   - 若 `base` 存在：对 `worlds`, `orgs`, `chars`, `templates` 按实体 ID 逐字段比对 `(baseVal, localVal, remoteVal)`：
     - 若仅一端修改，自动采纳修改端；
     - 若两端修改值相同，无冲突采纳；
     - 若两端将同一实体的同一字段改为不同值，记录到 `conflicts: FieldConflict[]`。
   - 返回 `{ canAutoMerge: boolean, mergedDoc: DocV6, conflicts: FieldConflict[], summary: DiffSummary }`。
3. **Wiki 分词与反向链接 (`backlinks.ts`)**：
   - `tokenizeEntityRefs(text: string, entities: EntityIndexEntry[], excludeId?: string)`：按实体名称长度降序前缀匹配（忽略少于 2 个字符的泛化词），返回安全的 Token 数组。
   - `renameEntityEverywhere(doc: DocV6, oldName: string, newName: string)`：返回新 `DocV6` 与替换计数，供改名联动与术语表替换复用。
