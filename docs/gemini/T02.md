# T02 —— 原 HTML 字典提取脚本与草稿码金标准样本生成

## 1. 背景与目标
原版 `/data/creator/legacy/index.html` 中包含约 1000 行精心编写的字段定义（世界观 `WG`、组织 `OG`、角色 `CG`、旧版顺序 `CHAR_OLD`）、灵感词库（`INSP_RAW`）、双语字典（`T`）、新手教程步骤（`TUT`）、内置模板（`DEFAULT_TEMPLATES`）以及头像预设列表（`AVATARS`）。手工复制极易漏字或破坏转义。
本任务编写 Node.js 自动化脚本 `scripts/extract-legacy.mjs`，利用 Node 内置 `vm` 沙箱直接执行原 HTML 中的数据定义与原版 `buildCode / parseCode / normalizeBackup / parseYear` 函数，自动生成 100% 精确的 TypeScript 模块与 **200+ 组金标准测试向量（Golden Master Fixtures）**。

## 2. 输入参考（原版 HTML 行号）
- `/data/creator/legacy/index.html`：
  - `L515–L551`：`CC.INSP_RAW` 与 `CC.INSP` 展开逻辑（按 `|` 切分中英文灵感词）
  - `L552`：`CC.CHAR_OLD`（兼容 CC1 草稿码的字段顺序）
  - `L554–L661`：`CC.CG`（角色字段分组）与 `CC.CHAR_ORDER`
  - `L663–L713`：`CC.OG`（组织字段分组）与 `CC.ORG_ORDER`
  - `L715–L767`：`CC.WG`（世界观字段分组）与 `CC.WORLD_ORDER`
  - `L770–L854`：`CC.T`（中英 UI 字典）与 `CC.TUT`（教程文案）
  - `L1169–L1226`：`SEP = '\u001F'`, `CC.buildCode`, `CC.parseCode`, `KIND_MAP`
  - `L1250–L1284`：`CC.checkConsistency` 规则表
  - `L1369–L1380`：`CC.parseYear` 年份解析逻辑

## 3. 产出文件清单
- `/data/creator/scripts/extract-legacy.mjs`
- `/data/creator/web/src/core/legacy/fields.ts`（自动生成：含 `CG`, `OG`, `WG`, `CHAR_OLD`, `CHAR_ORDER`, `ORG_ORDER`, `WORLD_ORDER`, `DEFAULT_TEMPLATES`）
- `/data/creator/web/src/core/legacy/insp.ts`（自动生成：含 `INSP_RAW`, `INSP`, `PERSONA_MAP`, `AVATARS`）
- `/data/creator/web/src/core/legacy/i18n.ts`（自动生成：含 `T`, `TUT`）
- `/data/creator/web/src/core/__fixtures__/golden-draft-codes.json`（自动生成：覆盖 `CC1`, `CC2`, `CC2O`, `CC3W`, `CC3I`, `CC3T`, `CC3P` 及含中文、Emoji、代理对、首尾空字段、连续空字段、换行符、`\u001F` 边界的 200 组双向样本）
- `/data/creator/web/src/core/__fixtures__/golden-backups.json`（自动生成：覆盖 v4 裸角色、v4 角色字典、v5/v5.1/v5.3 完整备份的原版 `normalizeBackup` 输出样本）
- `/data/creator/web/src/core/__fixtures__/golden-years.json`（自动生成：50 组纪元/正负年份文本及原版 `parseYear` 返回值）

## 4. 详细实现要求
1. 生成的所有 `.ts` 文件顶部必须带有 `// AUTO-GENERATED FROM legacy/index.html BY scripts/extract-legacy.mjs - DO NOT EDIT MANUALLY` 注释，并导出完整的 TypeScript 类型。
2. 支持 `--verify` 模式：重新在内存中提取并与磁盘上的 `.ts` / `.json` 比对，若字节不一致则非零退出（可加入 CI/Makefile 校验）。

## 5. 验收标准与验证命令
```bash
cd /data/creator
node scripts/extract-legacy.mjs
node scripts/extract-legacy.mjs --verify
cd web && npm run typecheck
```
