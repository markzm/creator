# T08 —— ⌘K 命令面板 / 备份导出 / 新手教程 / 字段引导 / 一键人设

## 1. 背景与目标
收尾纯前端功能闭环，并优化打包分块（Code Splitting）控制首屏体积：
1. **⌘K / Ctrl+K 全局命令与搜索面板（`CommandPalette.vue`）**：
   - 全库毫秒级全文检索（匹配世界观、组织、角色、事件、剧情、场景、术语），高亮命中片段，回车直达对应条目并定位字段。
   - 快捷命令执行：新建世界观/组织/角色、切换暗色模式、切换中英文、导出 JSON 备份、导出全库 Markdown 设定集。
2. **备份恢复与全库 Markdown 导出（`BackupModal.vue`）**：
   - 支持导出 `version: 6` JSON 备份文件；支持拖拽/选择任意旧版（v4/v5/v5.1/v5.3/v6）JSON 备份文件合并或覆盖导入（导入前自动创建 Undo 快照）。
   - 支持一键导出排版精美的全库 `.md` 设定集文档（移植 `L2886–L2966`）。
3. **新手教程与分步字段写作引导（`TutorialModal.vue`, `FieldGuideModal.vue`）**：
   - 完整保留原版 5 步交互式新手教程（`CC.TUT`）与逐字段提问式引导填写器（`CC.runGuide`，`L4090–L4167`）。
4. **角色一键人设生成器（`autoPersona` 集成）**：
   - 在角色页点击「✨ 一键人设」，按 `PERSONA_MAP` 随机抽取连贯的种族/职业/性格/外貌/动机组合填入当前角色。
5. **Vite 拆包优化**：
   - 在 `vite.config.ts` 中配置 `manualChunks`，将 `core/legacy/{fields,insp,i18n}` 拆为独立字典 chunk，确保首屏主 JS gzip 后 ≤ 120KB。
