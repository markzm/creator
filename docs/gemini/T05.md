# T05 —— 实体编辑器（世界观 / 组织 / 角色）+ 智能改名联动 + 高清图片卡

## 1. 背景与目标
实现设定创作器最核心的三大实体工作台（`World.vue`、`Org.vue`、`Char.vue`）及通用编辑器套件：
1. **中栏实体列表面板（`EntityListPane.vue`）**：替代原版 `<select>` 下拉框，支持搜索过滤、按更新时间/名称排序、新建、复制、删除实体，以及角色模板切换。
2. **右栏分组表单编辑器**：支持分组折叠、字段实时字数统计、总体完成度进度条、单字段「🎲 灵感骰子」（覆盖/追加模式）、自定义世界观灵感库管理（含 `CC3I` 灵感码导入导出）。
3. **Wiki 双向链接与改名联动**：
   - 在世界观关联面板、组织成员面板、角色关系面板以及预览抽屉中，点击实体名直接跳转对应实体。
   - 底部展示「🔗 反向引用（Backlinks）」面板（列出提及当前实体的所有其他条目）。
   - 修改实体名称失焦后，若存在反向引用，弹出「同步更新全库 N 处关联引用」一键替换条（支持 Undo）。
4. **辅助输出与高清图片卡（`imageCard.ts`）**：
   - 支持纯文本 / Markdown / JSON 实时预览与一键复制。
   - 完整移植原版 `L1285–L1368` 的 `CC.exportPng` 原生 Canvas 2D 高清图片卡生成（`DPR=2, CV_W=720`），零外部依赖导出 PNG。
