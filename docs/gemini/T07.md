# T07 —— 总览仪表盘 / 模板 / 剧情线 / 场景卡 / 术语表 / 写作看板

## 1. 背景与目标
完成创作辅助与管理模块群，以及兼顾新旧用户习惯的「🏠 总览（Dashboard）」首页：
1. **总览页（`DashboardView.vue`）**：
   - 顶部展示核心统计指标（世界观/组织/角色/剧情数、总设定字数、平均完成度、连续创作天数 🔥）。
   - 中部展示 **「最近编辑」** 快捷恢复卡片（按实体 `updatedAt` 取最近 6 个条目一键续写）。
   - 下部完整保留原版经典的 **模块九宫格导航大卡片**，让习惯原版九宫格跳转的用户无缝过渡。
2. **角色模板管理（`TemplatesView.vue`）**：
   - 内置预设模板（标准完整、极简快写、TRPG 跑团卡、反派/NPC）与自定义字段勾选模板；支持 `CC3P` 模板草稿码分享与导入，一键应用到当前角色。
3. **剧情线管理（`PlotsView.vue`）**：
   - 卷（Volume）→ 幕（Act）→ 章（Chapter）三级树形大纲；章节支持状态切换（`未写 / 写作中 / 已完成`）、关联时间与出场角色（名字支持 Wiki 点击跳转）。
4. **场景卡管理（`ScenesView.vue`）**：
   - 卡片网格展示地点、时间、出场角色、核心冲突与结果转折，支持按角色/关键词筛选。
5. **术语表与全局查替换（`GlossaryView.vue`）**：
   - 词条分类管理 + **全库查找与一键替换**（扫描所有世界观/组织/角色/剧情/场景/时间线，替换前自动保存 `_undoSnapshot` 并提供「撤销上次替换」按钮）。
6. **写作看板（`StatsView.vue`）**：
   - 原生 SVG 绘制近 14 天每日字数柱状/折线趋势图（移植 `L3340–L3399`），展示各模块字数占比与填写完整度排行。
