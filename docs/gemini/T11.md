# T11 —— 个人资料 / 头像上传 / 在线心跳 / 创作大厅与分享

## 1. 背景与目标
解决原版个人资料只存本地 `localStorage`、"我的分享"只在全站前 50 条里客户端过滤、以及匿名可爬数据的工程缺陷：
1. **个人资料与安全头像上传**：
   - `GET / PATCH /api/me`：读取与修改昵称（`name ≤ 16` 字符）、头像（Emoji 或 `/avatars/xxx.jpg`）、个人简介（`bio ≤ 80` 字符）。
   - `POST /api/me/avatar`：前端复用 `L3490–L3510` 的 Canvas 256×256 JPEG 居中裁剪压缩逻辑，上传 `multipart/form-data`（限制 `≤ 2MB`）；后端严格校验文件头魔数（JPEG `FF D8 FF` 或 PNG `89 50 4E 47`），使用 `image/jpeg` 重新编码剥离潜在 EXIF/恶意元数据后存为 `/var/lib/creator/avatars/u_<id>_<ts>.jpg`，并自动清理该用户的旧头像文件。
2. **在线状态心跳与创作大厅**：
   - `POST /api/presence`：每 60 秒（页面可见时）上报当前创作焦点 `{ focus: "正在创作世界观「艾泽拉斯」" }` 并更新 `last_seen_at`。
   - `GET /api/lobby/users`：需登录鉴权，返回 5 分钟内在线创作者及最近活跃创作者列表（绝不返回用户邮箱）。
3. **大厅分享与服务端游标分页**：
   - `POST /api/shares`：分享世界观/组织/角色到大厅（含标题、简介、格式化正文及可选草稿码，加发帖频率限制防刷屏）。
   - `GET /api/shares?owner=me&before=<cursor>&limit=20`：服务端直接按 `user_id` 或全站索引游标分页查询，彻底解决原版"超过 50 条就看不到自己分享"的 Bug。
   - `DELETE /api/shares/{id}`：服务端校验 `share.user_id == currentUser.id`（或管理员），非作者删除返回 `403 Forbidden`。
