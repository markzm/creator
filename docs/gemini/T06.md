# T06 —— 时间线视图（含年龄推算）+ 原生 SVG 关系网

## 1. 背景与目标
移植并增强设定集的两大可视化分析视图：
1. **时间线视图（`TimelineView.vue`）**：
   - 自动聚合全库时间线事件（手动添加的独立事件 + 从世界观历史、组织历史、角色生平中自动解析年份提取的事件）。
   - 支持正负年份（纪元前/纪元后）排序、按来源类型过滤、`CC3T` 时间线草稿码导入导出。
   - 完整保留原版 **「🎂 角色年龄推算器」**（设置基准年份 `nowYear`，选择角色与事件年份，自动根据角色年龄反推生年并计算事件发生时的岁数）。
2. **关系网视图（`GraphView.vue`）**：
   - 零第三方库，使用原生 SVG 渲染世界观、组织、角色三层关系网络。
   - 支持切换图层（`全部节点` vs `仅角色关系`）、鼠标拖拽节点改变位置、滚轮/按钮缩放平移、悬停高亮一度关联节点与关系标签、双击节点直接跳转到对应实体编辑页。
