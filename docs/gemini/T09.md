# T09 —— 后端基础架构 + SQLite WAL 双池 + 开放注册安全防护与账号体系

## 1. 背景与目标
构建零三方业务依赖的 Go 服务端基础框架、SQLite WAL 读写双连接池、自动数据库迁移以及具备**高强度安全防护的开放式账号体系（默认 `REGISTER_MODE=open`）**：
1. **SQLite WAL 读写分离连接池**：
   - 使用 `modernc.org/sqlite`（CGO-free）。
   - 启动时强制设置 `PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL; PRAGMA busy_timeout=5000; PRAGMA foreign_keys=ON;`。
   - 封装 `WriteDB`（`MaxOpenConns=1`，彻底串行化写事务，根治 `SQLITE_BUSY`）与 `ReadDB`（`MaxOpenConns=8`，并发查询）。
2. **账号体系与开放注册纵深防御（针对 `REGISTER_MODE=open` 强化）**：
   - 支持 `REGISTER_MODE=open`（默认，允许任何人注册）/ `invite` / `closed` 三种模式无缝切换。
   - **密码强度与存储**：强制要求密码长度 `8~72` 位且同时包含字母与数字；使用 `bcrypt`（Cost=12）哈希入库；登录失败统一返回「邮箱或密码错误」，防止枚举已注册邮箱。
   - **内置防刷算术/图形挑战（Captcha Challenge）+ 双维限流**：
     - 提供 `GET /api/auth/challenge` 生成带 HMAC 签名的短期无状态验证码挑战（或 SVG 图形验证码），开放注册时必须携带有效 `challengeToken` + `challengeAnswer`。
     - 内存级令牌桶限流器：按客户端 IP（注册每小时最多 5 个新账号，登录每分钟最多 10 次）+ 按目标 Email（10 分钟内连续失败 5 次即锁定该账号登录 15 分钟，防撞库）。
   - **会话管理**：登录成功后签发 32 字节 CSPRNG 随机 Token，客户端存 `HttpOnly; SameSite=Lax` Cookie（生产 HTTPS 自动开启 `Secure`），服务端 `sessions` 表仅存 `SHA-256(token)`，支持 30 天滑动续期与主动登出销毁。
   - **CSRF 防护**：所有 `POST/PUT/PATCH/DELETE` 接口强制校验 `Origin` 头与当前 Host 一致。
3. **内置运维 CLI 子命令**：
   - `creator serve`：启动 HTTP 服务。
   - `creator invite create -n 5`：生成邀请码（供切换至 `invite` 模式时使用）。
   - `creator user list` / `creator user reset-password --email x` / `creator user disable --email x`：管理员直接在服务器终端管理用户与重置密码。

## 4. 数据库 Schema (`001_init.sql`)
包含 7 张核心表：`users`（含 `is_disabled` 封禁标记）、`sessions`、`invites`、`user_docs`、`doc_revisions`、`world_shares`、`password_resets`。
