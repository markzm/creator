# T04 —— 设计系统 Tokens + 基础组件 + 应用外壳 + IndexedDB 存储层

## 1. 背景与目标
建立前端视觉基座与本地优先（Local-First）数据存储层：
1. 完整移植原版 CSS 变量体系（浅色与 `html.dark` 暗色主题）及微交互动画。
2. 构建约 15 个零依赖、高复用的基础 UI 组件（`components/base/*`）及响应式三栏应用外壳（侧边栏 + 顶栏 + 主工作区，移动端自适应底部 Tab）。
3. 实现基于 `idb-keyval` 的异步 IndexedDB 仓储层（`data/repo.ts`），支持首次启动自动从 `localStorage.getItem('cc_db_v5')` 迁移到 `DocV6`、通过 `BroadcastChannel` 实现多标签页实时状态同步，以及 `Pinia` 的 `doc` / `ui` Store。

## 4. 详细实现要求
1. **IndexedDB 与多标签页安全**：
   - 主文档存储在 IndexedDB key `creator_doc_v6`；基准同步快照存储在 `creator_base_doc_v6`。
   - 若 IndexedDB 为空且 `localStorage.getItem('cc_db_v5')` 存在，自动调用 `migrateToV6` 升级并写入 IndexedDB（不删除原 `cc_db_v5` 以防回退）。
   - 每次写入 IndexedDB 时，向 `BroadcastChannel('creator_v6_sync')` 发送 `{ senderTabId, updatedAt }`；其他 Tab 监听到后重新从 IndexedDB 加载最新 `DocV6`。
2. **保存状态反馈**：
   - `docStore` 修改后立即标记 `saving`，300ms 防抖写入 IndexedDB 后更新 `lastSavedAt`（顶栏显示「已保存 HH:MM」），同时触发 `syncStore.markDirty()`。
