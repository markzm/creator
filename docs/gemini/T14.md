# T14 —— Playwright E2E 冒烟测试 + 全量验收

## 1. 背景与目标
通过端到端真实浏览器自动化测试（Playwright）完成重构全链路验收，确保本地存储、旧备份兼容、开放注册与登录、多端云同步与冲突解决、创作大厅分享与权限隔离、双语与暗色模式全部符合设计预期。

## 2. 产出文件清单
- `/data/creator/web/playwright.config.ts`（自动拉起临时测试用 Go Server + SQLite 内存/临时文件库）
- `/data/creator/web/e2e/01-offline-crud.spec.ts`：离线创建世界观、组织、角色，填写字段，触发 Wiki 名字跳转与改名全局替换，刷新页面验证 IndexedDB 持久化不丢失。
- `/data/creator/web/e2e/02-backup-compat.spec.ts`：导入 v5.3 格式备份 JSON，验证所有模块（含时间线、剧情、场景、术语）完整恢复，并验证草稿码 `CC3W / CC2O / CC2` 导出与解析。
- `/data/creator/web/e2e/03-auth-and-sync.spec.ts`：在 `REGISTER_MODE=open` 下完成带验证码挑战的新账号注册与登录，模拟两个独立浏览器 Context 并发修改：
  - 场景 A：修改不同角色 → 自动触发三方合并（`threeWayMerge`）静默成功；
  - 场景 B：同时修改同一角色的同一字段 → 触发 `409` 红色冲突弹窗，手动选择合并方案并验证云端历史快照回滚。
- `/data/creator/web/e2e/04-lobby-shares.spec.ts`：用户 A 上传头像、发布世界观分享到大厅；用户 B 登录后在大厅可见该分享，但无删除按钮且直接调 `DELETE /api/shares/{id}` 返回 `403`；用户 A 在「个人主页 → 我的分享」中可正常删除。
- `/data/creator/web/e2e/05-theme-i18n-cmd.spec.ts`：验证 `⌘K / Ctrl+K` 命令面板全文搜索跳转、暗色模式切换、中英文切换（切换语言不丢失正在编辑的表单内容）。
