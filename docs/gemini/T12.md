# T12 —— 旧数据导入新系统 CLI (`creator legacy import`)

## 1. 背景与目标
将 T01 `legacy-export` 从旧 WorkBuddy 云端拉取下来的归档目录（`legacy-export-YYYYMMDD/`），通过服务端 CLI 命令 `creator legacy import --dir <path> --email <user@example.com>` 一键无损迁入新系统的指定账号中：
1. 若目标 `--email` 账号尚不存在，支持通过 `--create-user` 交互式设置新密码并自动建号。
2. 读取 `<dir>/db.json`（或 `<dir>/raw/user_sync.json`），在 Go 端自动执行 `v5 -> v6` 文档结构规范化（补齐 `_version: 6`、各实体 `id/createdAt/updatedAt`、将根级 `activeW/activeO/activeC/activeTpl/nowYear` 移入 `ui` 对象），写入 `user_docs` 并生成一条初始 `doc_revisions` 历史快照（标记摘要为 `legacy-import`）。
3. 读取 `<dir>/raw/my_presence.json` 与 `<dir>/avatar.jpg`，自动恢复用户的昵称、个人简介，并将头像复制到新系统的 `AVATAR_DIR` 下绑定到该用户。
4. 读取 `<dir>/raw/my_shares.json`，按原时间戳幂等导入到 `world_shares` 表，归属到新账号名下。
