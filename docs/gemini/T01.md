# T01 ⚡ —— 旧云端数据导出工具 (`legacy-export`)

## 1. 背景与目标
原版 v5.4 使用了第三方 WorkBuddy BaaS 服务（`@tencent-ai/workbuddy-cloud-sdk@dev`），随时可能下线。本任务编写一个**零外部业务依赖、纯只读**的独立 Go CLI 工具 `legacy-export`，通过终端安全交互输入手机号与密码（密码不回显、不落盘），将用户的 `user_sync`（整库数据）、`user_presence`（个人资料与头像）、`world_shares`（已发布的分享）以及 `img:` 签名头像图片完整拉取到本地归档目录，并生成可直接导入 v5.4/v6 的标准备份文件 `db.json`。

- **已验证 HTTP 协议细节**：
  - 所有请求携带 Header：`x-wb-webapp-access-key: <publishableKey>`；登录后额外携带 `Authorization: Bearer <access_token>`。
  - **手机号规范化**：11 位大陆手机号 `13xxxxxxxxx` 转换为 `+86 13xxxxxxxxx`（注意 `+86` 后有一个空格）；若传入邮箱则原样作为 `username`。
  - **登录接口**：`POST {endpoint}/.cloud/auth/v1/signin`，JSON Body `{"username":"+86 13xxxxxxxxx","password":"..."}` → 返回 `{"access_token":"...","refresh_token":"...","sub":"<uid>",...}`。
  - **PostgREST 数据查询**：
    - `GET {endpoint}/.cloud/database/rest/user_sync?select=*`
    - `GET {endpoint}/.cloud/database/rest/user_presence?select=*`
    - `GET {endpoint}/.cloud/database/rest/world_shares?select=*&order=created_at.desc`
  - **Storage 签名 URL 接口**：
    - `POST {endpoint}/.cloud/storage/object/sign/runtime`
    - JSON Body：`{"expiresIn":3600,"paths":["users/<uid>/avatars/xxx.jpg"]}`
    - 返回数组 `[{"path":"...","signedURL":"/object/sign/runtime/..."}]`，拼接 `{endpoint}/.cloud/storage{signedURL}` 即可 `GET` 下载头像二进制。

## 4. 详细实现要求
1. **命令行参数**：
   - `--endpoint`（默认 `https://worldbuilding-studio.app.workbuddy.host`）
   - `--key`（默认 `wbpk_dfTf91HpFpdkFVXmZqLgMk_1zFbEtYdRNt6Tbm5WtDIshZ4QkvQkGSm`）
   - `--phone` / `--username`（可选，未传时终端交互提示输入）
   - `--out`（默认 `./legacy-export-YYYYMMDD-HHMMSS`）
2. **安全密码读取**：
   - 使用 `golang.org/x/term.ReadPassword(int(os.Stdin.Fd()))` 无回显读取密码；严禁通过命令行 flag 接收明文密码（防写入 `.bash_history`）。
3. **导出产物结构**：
   - `<out>/raw/auth_user.json`（脱敏 token 后的用户信息：`sub`, `name`, `phone`）
   - `<out>/raw/user_sync.json`（原始 `user_sync` 表返回）
   - `<out>/raw/user_presence.json`（原始 `user_presence` 表返回，以及筛选出的当前用户记录 `my_presence.json`）
   - `<out>/raw/world_shares.json`（原始 `world_shares` 表返回，以及筛选出的当前用户分享 `my_shares.json`）
   - `<out>/db.json`：解析 `user_sync[0].data` 中的 JSON，并包装成标准备份格式 `{"version":5.3,"ts":...,"worlds":...}`（同时保留原始 `cc_db_raw.json`），确保既能直接点旧版页面「恢复备份」导入，也能被 T12 的 `creator legacy import` 读取。
   - `<out>/avatar.jpg`：若用户的 `avatar` 字段以 `img:` 开头，自动调用签名接口并下载保存图片文件。
   - `<out>/manifest.json`：记录导出时间、用户 `uid`、世界观/组织/角色/时间线/剧情/场景/术语/分享的统计数量。
4. **单元测试（`exporter_test.go`）**：
   - 使用 `httptest.NewServer` 完整模拟 WorkBuddy 的 `/.cloud/auth/v1/signin`、`/.cloud/database/rest/*` 和 `/.cloud/storage/object/sign/runtime`，测试手机号格式化、登录鉴权、JSON 解包、本人记录过滤、签名头像下载与文件落盘全流程。
