# Cloudflare 创作管理与 AI 防滥用升级

本次变更适用于 Worker/D1 与 Vue 前端。Go 服务未调整；新增的管理和配额接口需要部署配套 Worker。

## 上线顺序

先备份，再预检、迁移，最后发布 Worker 与前端。在迁移和发布期间暂停作者写入，避免旧 Worker 跳过新增版本协议。

```bash
mkdir -p backups
npx wrangler d1 export creator-db --remote --output backups/before-creator-upgrade.sql
npm run d1:preflight:remote
npm run d1:migrate:remote
npm run deploy
```

预检只读 `users`。数据库必须恰好有一位现有超级管理员，而且该账号同时是普通管理员、未禁用、未禁言；任何异常都会中止，不会自动选人或降级。`0007` 自身也检查相同条件。请核对预检打印的 UID 和邮箱是否为应保留的账号。

迁移后，该超级管理员不能被转移、撤销、删除、禁用、禁言或通过 `INSERT OR REPLACE` 替换。界面与角色 API 只能授予普通管理员。

空数据库不能直接执行完整迁移：先用上一版本完成 `0001`–`0006` 建表与账号注册，由运维明确确认唯一账号，再在受控流程中设置其 `is_admin=1, is_super_admin=1`，然后运行本版预检和 `0007`。本版不会为全新数据库自动指定管理员。不要删除保护触发器来修复存量角色异常；应在迁移前处理并再次核对。

本地数据库使用对应的 `d1:preflight:local`、`d1:migrate:local`。自动化测试使用独立、内存中的 D1，不读取 `.wrangler` 或线上数据。

## 创作管理与同步

超级管理员导航中的“全站创作管理”可按昵称或邮箱分页查找作者。它使用独立编辑缓冲区，不改变管理员自己的设定集。

云端设定集包含作者已经同步的私有、未发布内容；尚未同步的设备数据无法读取。作品库管理独立的分享副本。编辑一份不会自动更新另一份，界面会提示分别保存。

设定集使用 `baseRev`，分享修改、删除和审核使用 `rev`。冲突返回 `409`；界面保留编辑草稿，需保留所需修改后重新载入合并。重新发布发生冲突时，会先展示云端和本地内容摘要，明确确认后才能用新版本提交；被删除的分享不会静默复活。管理操作在同一 D1 事务中保存修改前快照、审计记录及版本更新。作者继续通过原有三路合并同步，删除与修改同时发生时需明确选择。普通管理员只能治理公开内容，不能通过详情、评论、点赞、删除或审核入口读取其他作者的私有作品。

同步使用忽略界面状态的内容哈希。相同内容不增加版本、不生成快照；旧文档第一次同步会补齐哈希。一般同步仅查版本与哈希，发生冲突或补齐旧哈希时才读取完整文档。快照继续保留最近 50 份及近 30 天每日一份；审计记录独立保存。

## 提示词与 AI

个人提示词库支持分类、搜索、复制、关联设定与适用任务。模板保存在可选的 `DocV6.promptTemplates` 中，参与本地保存、备份与按 ID 合并；旧备份缺失时视为空集合。官方范例和公开分享的导出路径不携带该集合。

AI 草稿窗口可以自由输入，也可以选模板或先让 AI 生成、润色提示词。默认资料来自当前目标及明确关联的世界观、组织、角色，作者可以调整并预览。仅在其他页面选中某个条目不会建立归属关系。材料最多 24,000 字符，优先保留目标内容，并显示裁剪提示。

字段生成、完整设定、文章创作、续写和摘要均先生成可编辑草稿，再选择替换、追加或放弃。目标已删除或变化时会阻止直接替换；摘要还会检查来源正文是否变化。生成文本不作为 HTML、脚本或远程资源执行。

服务端固定任务和消息角色；模板、偏好和资料通过结构化用户内容提供，不能替换系统规则。接口没有数据库查询和管理工具，不发送其他作者内容、会话或密钥。明确的越权、系统指令提取和密钥泄露请求会被拒绝，返回结果也检查密钥泄露。防护采用输入校验、固定任务、权限隔离、结构化材料、输出检查和配额多层限制，不依赖独立审核模型，也不承诺仅凭关键词消除所有提示词注入。

## 部署配置

在 `wrangler.toml` 的 `[vars]` 中配置以下值。密钥继续通过 Wrangler secrets 设置，切勿写入仓库或日志。

| 变量 | 默认值 | 约束 |
| --- | ---: | --- |
| `AI_PUBLIC_MINUTE` | 5 | 每人每分钟，上限 100 |
| `AI_PUBLIC_DAILY` | 50 | 每人每天，上限 10,000；北京时间零点重置 |
| `AI_CUSTOM_MINUTE` | 30 | 个人 Key 每分钟，上限 100，无每日限额 |
| `AI_TIMEOUT_SECONDS` | 90 | 上游超时，可调低，上限 90 秒 |
| `AI_MAX_INPUT_BYTES` | 131072 | 请求体上限，可调低 |
| `AI_MAX_OUTPUT_TOKENS` | 4096 | 输出 token 上限，可调低 |

公共提示词生成、润色和正文任务共享公共配额。公共模型只接受 `openrouter/free`。每次调用必须明确选择 `provider: public` 或 `custom`；个人服务缺少有效配置时不会改用公共额度。连接测试每分钟 3 次。

D1 原子计数与带过期时间的租约在 Worker 实例间共享；每个用户最多一个在途任务，公共、个人服务及连接测试共用并发锁。上游失败、超时后释放租约，Worker 异常退出时由租约过期恢复。无法确认额度时返回 `503`，不调用公共模型；限流返回 `429` 及 `Retry-After`。辅助 IP 限制为每分钟 60 次。

上游只允许受信任的 HTTPS 主机，不跟随重定向；错误响应脱敏。日志只包含任务运行元数据，不记录原始提示词、会话和密钥。每日定时任务按索引、每批最多 2,000 行清理超过 48 小时的 IP 计数；用户配额及并发租约行保留复用。

公开统计和创作者资料在客户端与 Worker 内缓存 30 秒并合并在途请求，相关写入会失效缓存。缓存属于单个 Worker 实例，其他实例至多保留 30 秒旧公开数据。权限、私有内容、作品详情不做跨请求缓存，API 响应使用 `Cache-Control: no-store`。通知轮询只取未读数，展开才读取详情，后台页面暂停请求；心跳写入按 60 秒节流。

## 验证与观察

```bash
npm ci
npm ci --prefix web
npm run typecheck:worker
npm run typecheck --prefix web
npm run test --prefix web
npm run test:worker
npm run test:e2e:worker
npx wrangler deploy --dry-run --outdir /tmp/creator-worker-dry-run
```

浏览器测试需要 Playwright Chromium，或设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向本机 Chrome。测试运行器会在 macOS 自动使用已安装的 Google Chrome；不启动真实用户浏览器会话。

Worker 测试覆盖异常迁移、四类访问者权限、事务回滚、两个 Worker 实例共享版本与配额、北京时间日额度、超时释放、输入输出保护，以及游标分页与查询计划。浏览器测试使用 1,000 位作者，连接真实本地 Worker/D1；AI 上游由测试替身响应，不使用生产 Key。截图输出到忽略提交的 `artifacts/e2e/`。

企划性能测试按旧版实际成员查询与逐企划计数建立基线，记录 SQL 次数和 D1 `rows_read`，并检查索引使用。上线后对比 D1 的读取/写入行数、接口延迟、`409` 比例、AI `429/422/503/504` 及异常租约。不要启用请求体日志来排查 AI 拦截。

升级失败时先停止写入，保留备份及当前数据，再使用 D1 恢复流程恢复完整数据库并回退配套 Worker/前端。不能只回退旧 Worker：旧版不遵守分享版本和 AI 配额协议。本次开发和自动化验证不会执行生产迁移或发布。
